FAQ

Windows only?

Yes for this release - Windows .exe only. Mac is not included. If enough people ask, we will consider Mac later.

Do I need MT5?

No for the offline calculators. Live drawdown room and open-position risk need MetaTrader 5 open and logged into your challenge account on the same Windows PC.

Which prop firms?

Any firm you trade in MT5 on Windows (FTMO, FundedNext, Eightcap challenges, and similar). PropGuard does not log into firm websites. It only reads the local MT5 terminal. Preset defaults start with Eightcap $5k One Phase - edit Daily %, Total %, Target % for your rules.

Can it trade for me?

No. Read-only. It never places, modifies, or closes orders.
